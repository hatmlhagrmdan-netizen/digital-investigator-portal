# بوابة المحقق الرقمي

منصة عربية متخصصة في الأمن السيبراني والذكاء الاصطناعي والتحقيقات الرقمية.

## أهداف المشروع

- منصة عربية للأمن السيبراني.
- منصة للتحقيقات الجنائية الرقمية.
- مكتبة أدوات احترافية.
- دورات تدريبية.
- مقالات تقنية.
- مساعد ذكاء اصطناعي عربي.
- لوحة تحكم للإدارة.
- نظام تسجيل دخول.
- قاعدة بيانات Firebase.
- جاهز للنشر على GitHub وCloudflare Pages.
